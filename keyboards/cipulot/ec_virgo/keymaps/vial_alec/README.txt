Virgo EC vial_alec

Based directly on the supplied working vial keymap/layout.
The original 93-position LAYOUT() definitions are unchanged.
Measured EC calibration defaults are applied at boot.
No LTO setting is added.

Install as:
  keyboards/cipulot/ec_virgo/keymaps/vial_alec

Build:
  make clean && make cipulot/ec_virgo:vial_alec
