# Canonical EC42 v2.9

The authoritative wire table and record schema are in ../../README.md sections4/5.
Firmware and GUI share ../common/interfaces/ec42_protocol.h (from framework root).
All three boards report minor 9/capabilities0x66/descriptor format 1 and use the same
explicit record method 0x42, length 17+3*N. Profile magic and geometry bind records.
No model-specific serialization or automatic/timed calibration exists.

Only v2.9 is supported. The old radix codec, earlier telemetry shapes and frozen
historical engine fixture have been removed. Current-source harnesses compile
all three boards and share the GUI integration tests. Invalid and interrupted
current records remain protected by validation, CRC and storage checks.
